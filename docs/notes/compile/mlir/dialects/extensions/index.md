# 领域表示与扩展入口

前面的张量、循环、内存与目标主线提供共同基础。进入具体模型和工具时，还可能需要保存数值映射、稀疏结构、动态形状条件，或采用项目的交换表示。本模块给出可推演的入口，帮助判断何时需要继续深入相应领域。

| 章节 | 具体过程 | 本次证据 |
|---|---|---|
| [量化类型](./quantization) | 实数→整数存储→恢复值；连接整数累加与输出缩放 | 类型/操作往返、存储反例、独立数值模型 |
| [稀疏编码](./sparse) | 2×3矩阵→CSR→按条目循环 | 真实sparsification与存储模型 |
| [Shape约束](./shape) | 广播尺寸→witness→动态断言 | 静态折叠与cf.assert输出 |
| [IRDL定义](./irdl) | 定义IR→动态加载→约束检查 | 类型反例及缺少效果信息对照 |
| [StableHLO与TOSA](./graph_ir) | 张量交换边界→后端结构化表示 | TOSA真实转换；StableHLO官方定位 |

数学相关的[复数语义](../math/complex)归在Math模块。每篇明确自己的验证层次；这里没有把结构验证或公式模型记为领域运行时/设备执行。
