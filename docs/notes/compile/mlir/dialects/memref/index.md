# MemRef：存储、布局与视图

张量计算最终要读取与写入存储。这个模块从一个二维数组进入：先取得存储并访问元素，再计算索引对应的地址，最后通过窗口更新观察多个视图如何共享同一次分配。

```text
分配与访问 → 坐标、offset 与 stride → 子视图与别名
                                         ↓
                      Bufferization：选择怎样实现张量值
```
