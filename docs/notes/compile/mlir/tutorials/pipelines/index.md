# 编译流程贯通

选择同一个计算，观察每一阶段新增了什么实现细节、保留什么语义。

当前已有整体导读、固定 torch-mlir 的前端源码路径，以及 Linalg 到 CPU 的完整 C 调用教程。源码核验与实际执行分别标注。

## 阅读前置

总览在 Conversion 基础后阅读；后两篇按 Tensor/Linalg、内存和 lowering 的前置推进。
