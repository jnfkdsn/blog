# 低比特量化

量化用更少的比特表示权重、激活或缓存，以减少存储与数据搬运，并在硬件支持时使用相应的低精度计算。理解量化需要同时观察数值误差、实际执行的数据流，以及部署后的性能。

这组内容整理自 [A Survey of Low-bit Large Language Models: Basics, Systems, and Algorithms](https://doi.org/10.48550/arXiv.2409.16694) 的阅读笔记，按主题拆分保留原有解释。文中工具和算法描述属于该综述笔记的范围，不能据此推断某个当前软件版本已支持相应实现。
